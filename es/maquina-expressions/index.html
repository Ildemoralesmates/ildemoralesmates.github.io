Máquina de expresiones

Entra un número, sale otro. Cada caja es una operación y la cadena de cajas es una expresión algebraica.

Construye la máquina o adivínala

Cada caja hace una operación con el número que entra. Si encadenas × 3 y + 2, la máquina calcula 3x + 2. Cambia el orden de las cajas y mira cómo cambia la expresión, o prueba entradas para descubrir la regla secreta de una máquina cerrada.
