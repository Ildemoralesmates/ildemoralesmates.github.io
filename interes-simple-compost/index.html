Interés simple i compost: la bola de neu

Amb interés simple, els diners creixen en línia recta. Amb interés compost, els interessos també generen interessos… i la diferència acaba sent enorme.

El compte d'estalvis

Interés simple: cada any es cobra el mateix interés, calculat sempre sobre el capital inicial: C = C0 · (1 + r · t). Interés compost: l'interés de cada any s'afig al capital i, l'any següent, també genera interés: C = C0 · (1 + r)t. Al mode Capitalització veuràs què passa si els interessos s'afigen cada mes, cada dia… o a cada instant.

La idea: l'interés simple creix de manera lineal (cada any suma el mateix) i el compost, de manera exponencial (cada any multiplica per 1 + r: és l'índex de variació anual). Les capes són els termes del binomi: (1 + r)t = 1 + t·r + C(t,2)·r² + …; el primer terme és el capital, el segon és exactament l'interés simple i la resta són «interessos d'interessos», que al principi són xicotets però acaben manant.
La idea: el TIN és el tipus «de cartell»; si es capitalitza n vegades a l'any, cada vegada s'aplica r/n. La TAE (taxa anual equivalent) és el que creix de veritat en un any: TAE = (1 + r/n)n − 1. Com més sovint, més TAE… però amb fre: el límit és er − 1.
